# Rencana paket 8c-3: kalimat "Terdaftar" sesudah rilis

20 November 2026 · di-"buat" pemilik 20 Nov 2026 15.33 WIB · temuan uji nyata gerbang Tahap 8 (akun kedua mendaftar sebagai 10735, 15.31 WIB)

## Temuan [Pasti]

Balasan "Terdaftar: … Rincian gaji akan dikirim lewat chat ini setelah gaji dirilis." muncul tepat sebelum rincian gaji periode terakhir; janggal.

## Isi paket

1. Bot: bila rincian terakhir ada, kalimat diganti "Rincian gaji terakhir ada di bawah ini; tombol Gaji saya untuk meminta ulang."; bila belum ada gaji dirilis, kalimat lama tetap.
2. Uji bot untuk kedua keadaan; bukti uji bisa gagal. Tanpa migrasi.
3. Pasang. Uji nyata butuh akun yang belum terdaftar (akun ketiga); bila belum ada, cukup uji otomatis.
